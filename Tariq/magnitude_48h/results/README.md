# Magnitude results

[Experiment registry](experiment_registry.csv) records magnitude research history. [Milestone scores](magnitude_48h/improvement_history.csv) show benchmark progression. [Target table](target_horizon_matrix.csv) identifies the 48-hour target.

Scores use log basis points; improvement is baseline minus candidate. Historical verification does not imply all old model binaries remain available. Current files are listed in the artifact manifest.
