# Get the required data

The repository contains research code and evidence. It does not contain the original datasets.

| Need | Where to find it | Access |
| --- | --- | --- |
| Magnitude inference inputs | Four prepared X/y Parquet files in the original playground data folder | Company research owner; shared storage location not yet confirmed |
| Original F4/F4Z archive | [Private Drive file](https://drive.google.com/file/d/1RXZDR_PaLkKMYtuswOBnl4_0eG9_LkNx/view) | Separate Drive permission |
| Canonical targets archive | [Private Drive file](https://drive.google.com/file/d/1y351d1ibxpAH-MxijvGDHPWEfqOJ70aM/view) | Separate Drive permission |
| General timing outputs/checkpoints | [Output folder](https://drive.google.com/drive/folders/1DXhoOLybfhEIt3phvPfG3cL3M31FPFEC) | Separate Drive permission |
| Completed staged outputs | [Staged folder](https://drive.google.com/drive/folders/1-Ly5SHesR7s2xd9eftlxlVCvsmOyJHlI) | Separate Drive permission; local receipts already included |

Exact sizes, required roles, recorded checksums and availability are in [external artifacts](../artifacts/external_artifacts.json). Magnitude prepared-input SHA-256 checksums were recomputed locally. Archive MD5 checksums come from saved source identities, not a new remote audit.

Do not download full source ZIPs to a PC just to read the research or check saved scores. The timing code uses controlled archive reads and private caches in its original cloud workflow. Any future data-level run needs an approved execution plan and access. Skip all July 2024 and later timing source partitions.

GitHub membership does not grant Drive access. The original prepared-data location is machine-specific; ask the company owner for approved sharing rather than committing data to GitHub. Current magnitude prediction evidence is intentionally retained and must be included in the final company-content review.
