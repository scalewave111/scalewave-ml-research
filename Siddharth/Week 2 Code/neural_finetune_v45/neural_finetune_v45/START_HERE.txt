WHAT CHANGED
We started from the saved 32-epoch neural weights instead of training new networks
from scratch. The logistic base, input admission, missing-value handling, scaling,
network architecture, correction bound and 75/25 prediction blend were retained.

Branch A: update only the final output layer; hidden-layer weights remain fixed.
Branch B: update all neural layers gently.
Each branch uses three original seeds and 16 additional epochs, learning rate
0.0003, AdamW weight decay0.01, full batches, gradient clipping1. Dropout is disabled
during fine-tuning to keep the small updates stable. The loss combines binary
cross-entropy, Brier loss and a penalty for departing from the original correction.

The candidate is the equal average of both branches and all three seeds. This
combination was fixed before training. We did not select whichever branch or seed
looked best afterward. The model still limits the neural logit correction to0.15*tanh.

Both metrics improved in two of three chronological periods. Two of the three
single-seed, two-branch averages beat the three-seed reference on both pooled
metrics. This is a comparison against the ensemble reference, not a matched-seed
causal attribution of fine-tuning. The pooled candidate uses all seeds throughout.

Head-only fine-tuning improved both scores in all three periods as a diagnostic;
it was not substituted for the registered combined candidate. Development was
scored only for the registered candidate, after it passed the fixed gate.

DECISION
Keep the prior frozen baseline intact and retain this slightly better exploratory
candidate for comparison on genuinely new data. The targets0.65 and0.50 were not
reached. Do not present this tiny improvement as a major modeling breakthrough.
